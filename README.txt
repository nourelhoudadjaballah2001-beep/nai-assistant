مساعد ناي - مشروع Android Studio
1) ضع ملفات خط Tajawal (ttf) في app/src/main/assets/fonts/ (الأسماء في README هناك).
2) Android Studio: File > Open > هذا المجلد > Build > Build APK(s)  (الناتج: app/build/outputs/apk/debug)
   أو ارفع المجلد إلى GitHub فيبني Actions ملف APK تلقائيًا (Actions > Artifacts).
تحديث التطبيق: عدّل app/src/main/assets/index.html ثم أعد البناء.
